# Security policy

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ever-guild/AgentShelf/security/advisories/new). This channel is enabled for this repository and requires a GitHub account.

Include the affected URL or version, reproduction steps and expected impact. Redact passwords, authorization tokens, payment approval URLs and personal information. Do not post security reports in public issues.

AgentShelf currently runs only against PayPal Sandbox. Please do not test against PayPal Live, access another user's records or create payments as part of a report. Maintainers will coordinate any further investigation privately.

Reports are reviewed by the project maintainers. There is no guaranteed response time or bug bounty. Ordinary support questions belong in GitHub issues, without sensitive data.
